# M10 中文财经新闻源改造

## 数据源

M10 保持既有 `SourceAdapter → RawNews → NewsItem → Event → AI → Notification` 链路，数据源顺序调整为：

1. 中新网官方财经 RSS：默认中文主源
2. 钛媒体官方 RSS：可选科技、商业补充源，默认关闭
3. CNBC RSS：国际财经备用源

金十开放平台适配器继续保留在代码中，但默认关闭；当前方案不使用金十、Tushare news、RSSHub、AKShare 或任何网页内部接口。M8 行情、M9 基金、AI Provider、通知和企业微信链路没有重构。

只读取 RSS 提供的标题、摘要、发布时间、来源和原文链接，不抓取中新网文章正文。

中新网与钛媒体官方 RSS 不需要 Token。AI 和企业微信配置仍由现有环境变量控制，密钥不得写入日志或 API 响应。

## RSS 增量与幂等

- `SourceCursor.cursor_data` 保存 `etag`、`last_modified`、`last_checked_at`、HTTP 状态、当前 entry hash 和 Feed 是否追平。
- Feed 追平后发送 `If-None-Match` 与 `If-Modified-Since`，正确接受 HTTP 304。
- 首次采集超过每轮上限时不发送条件请求，按发布时间从旧到新分批追赶，避免 304 导致未处理条目被跳过。
- 优先使用 RSS `guid`，否则使用去除片段的原文链接作为稳定 `source_item_id`；两者都缺失时才使用标题与发布时间哈希。
- entry hash 由规范化 RSS 字段生成，同时作为 RawNews 修订号。同一 ID 内容变化会新增 RawNews 修订并更新既有 NewsItem，不会新增重复 NewsItem。
- 单个来源在独立事务中执行；失败只回滚该来源，不停止其他来源或 Worker。

无需新增数据库表或 Alembic migration，现有 `SourceCursor.cursor_data` 已能保存条件请求元数据。

## Event 与读取

`DeterministicEventMatcher` 继续在唯一匹配边界内使用三小时时间窗、标题归一化、中文双字词、财经实体和序列相似度。小程序新闻 API 每个 Event 只返回一个代表 NewsItem，代表来源优先级为中新网、钛媒体、CNBC；历史 CNBC 数据不删除。

## 中文 AI

`event-analysis/m10-zh-v1` 要求 `summary`、`category` 和 `market_impacts.reason` 等用户可见字段使用简体中文，并继续遵循既有 JSON Schema。AI 不承担英文新闻逐句翻译。
