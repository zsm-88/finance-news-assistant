# M8 行情中心与全局中文化

## 实现范围

M8 增加只读实时行情数据层、Redis 短缓存、微信行情 API、行情中心、行情详情和首页行情摘要。没有新增数据库表，没有改动新闻采集、AI 分析、通知决策或企业微信推送。

支持 12 个标的：上证指数、深证成指、创业板指、沪深300、纳斯达克指数、标普500指数、道琼斯指数、恒生指数、恒生科技指数、黄金、原油和美元指数。

## 行情数据源

当前 Provider 使用 Yahoo Finance Chart 接口：

```text
https://query1.finance.yahoo.com/v8/finance/chart/{symbol}
```

选择原因是一个接口可覆盖 M8 的 12 个目标标的，返回价格、前收盘价和更新时间，不需要在小程序或后端配置 API Key。后端将第三方代码映射到稳定的内部代码，小程序不直接请求 Yahoo。

### 使用限制

- 该 Chart 接口没有公开 SLA，字段、限流策略和可用性可能变化。
- Yahoo Finance 数据适用于本项目的个人、非商业用途。商业使用、再分发或公开发布前必须重新核对 Yahoo 条款并选择有正式授权的数据供应商。
- 数据可能是延迟行情，不用于下单、交易执行或精确估值。
- 当前没有可靠的分钟历史序列契约，因此 M8 不绘制日内走势图。
- Provider 对单个标的失败进行隔离；全部失败时 Service 返回 12 个标的及空价格，界面显示“暂无数据”，不会生成或写死价格。

## Provider 设计

```text
微信小程序
  -> FastAPI
  -> MarketService
  -> MarketCacheRepository
  -> MarketProvider
  -> Yahoo Finance
```

`MarketProvider` 是统一协议。`YahooFinanceProvider` 负责 HTTP 和第三方字段解析；`MarketService` 负责缓存编排、标的白名单和失败降级；`MarketCacheRepository` 只负责 Redis 序列化。以后更换正式供应商不需要修改 API 或小程序。

统一字段为 `symbol`、`name`、`market`、`asset_type`、`price`、`change`、`change_percent`、`timestamp`、`market_status`、`source` 和 `is_delayed`。涨跌额和涨跌幅根据当前价与第三方返回的前收盘价计算。

## API

```text
GET /api/v1/wechat/market
GET /api/v1/wechat/market/{symbol}
```

列表返回全部 12 个标的、生成时间和缓存秒数。详情仅接受小写字母、数字和下划线组成的白名单代码；格式非法返回 422，未知代码返回 404。合法标的数据源不可用时返回 200 和空价格，便于页面准确显示“暂无数据”。

## Redis 缓存

缓存键为 `market:{symbol}`，默认 TTL 为 60 秒。首次请求访问 Provider 并写入 Redis，TTL 内的后续列表或详情请求直接命中缓存。第三方失败产生的“暂无数据”结果也短缓存 60 秒，避免故障期间形成重试风暴。行情不会逐秒写入 PostgreSQL，也没有新增行情历史表。

可选配置：

```env
MARKET_DATA_SOURCE_URL=https://query1.finance.yahoo.com
MARKET_CACHE_TTL_SECONDS=60
MARKET_REQUEST_TIMEOUT_SECONDS=10
```

## 刷新策略

行情页打开时加载，支持下拉刷新、手动刷新，并在页面可见时每 60 秒自动刷新。页面隐藏或销毁后停止定时器。所有刷新仍经过后端 Redis 缓存，不会每秒访问第三方。

## 市场状态与时区

API 内部状态为 `trading`、`closed`、`pre_market`、`post_market`、`unavailable`，小程序分别显示“交易中”“已收盘”“盘前”“盘后”“暂无数据”。

- A股和港股按 `Asia/Shanghai` 的工作日及午间休市判断。
- 美股按 `America/New_York` 判断盘前、正常交易和盘后。
- 黄金、原油和美元指数按纽约工作日的近 24 小时交易窗口近似判断。
- 行情时间戳使用第三方 Unix 时间转换为带时区的 ISO 8601，页面按设备本地时区显示中文日期。

已知限制：当前未集成交易所节假日日历，也没有精细处理期货每日维护窗口。节假日可能被显示为交易中；正式交易用途需要引入有授权的交易日历和供应商市场状态字段。

## 中文化

TabBar、页面标题、按钮、加载/空/失败状态、新闻元数据、AI 分析字段、市场方向、行情字段、市场状态、日期时间、基金页面和 AI 页面均以简体中文显示。股票代码、Yahoo Finance、CNBC 和 AI 等固有名称保留英文。

## 真实验证与已知问题

2026年8月8日开发机真实验证结果：12 个第三方代码请求均成功，Docker API 返回 12 项且全部具有真实价格；首次请求约 944ms，第二次 Redis 命中约 34ms；Redis 生成 12 个 `market:*` 键，抽样 TTL 为 59 秒；列表和详情 API 均返回成功。

微信开发者工具已识别项目，模拟器日志未发现语法或运行时错误，并记录到热更新后的 `wx.request` 成功回调。官方 CLI 无法附着已运行的 IDE，M8 行情中心和详情页的最终视觉点击验收仍标记为 Pending，需在当前开发者工具窗口中人工确认。小程序真机仍需公网 HTTPS API 域名和微信公众平台 `request` 合法域名。
