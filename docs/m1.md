# M1 项目初始化

M1 只提供工程基础设施，不包含新闻采集、Event 聚合、AI 分析、去重、评分或推送业务逻辑。

## 已交付

- Python 3.12+ 项目元数据和开发依赖
- `src/app` 基础包、FastAPI 生命周期和 `/health`、`/ready` 骨架
- Pydantic Settings 配置入口与 `.env.example`
- SQLAlchemy async engine/session 工厂和 Redis 客户端基础设施
- Alembic 配置及空迁移目录
- Dockerfile 与 Docker Compose：api、worker、scheduler、PostgreSQL、Redis
- 结构化日志配置入口
- pytest 健康检查测试
- GitHub Actions：ruff、mypy、pytest

## 本地验证

```powershell
Copy-Item .env.example .env
docker compose up --build
```

服务启动后：

```powershell
Invoke-RestMethod http://localhost:8000/health
Invoke-RestMethod http://localhost:8000/ready
```

当前开发环境未提供 Docker，且 Python 依赖安装因网络超时未完成；已完成 `compileall` 语法检查，运行时验证需在具备 Docker/依赖缓存的环境执行。
