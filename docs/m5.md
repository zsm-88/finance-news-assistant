# M5 Notification Framework

M5 提供 Event 级通知决策和渠道交付框架，不包含日报、RAG 或 AI 问答。

核心入口为 `NotificationService.process(event, preference, channel, destination)`：

1. DecisionEngine 检查订阅偏好、最低重要性、静默时段和现有待发通知。
2. 创建 Notification，并将决定写入 NotificationTimeline。
3. 延迟通知停留在 `delayed`；重复更新由 MergeEngine 合并；忽略记录为 `ignored`。
4. 立即通知通过 PushChannelRegistry 获取渠道并发送。
5. 每次渠道交付创建或更新 PushDelivery，成功和失败均写入 Timeline。

企业微信是第一个 PushChannel，通过 webhook 发送 markdown；新增渠道只需实现 `PushChannel` 协议并注册。
