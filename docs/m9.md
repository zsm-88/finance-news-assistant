# M9 基金中心

## 实现范围

M9 完成“基金查询 + 自选 + 持仓 + 实验性盘中估值”的基础闭环：

- 基金代码/名称搜索、基金详情、自选增删。
- 持有份额和平均成本持久化。
- Tushare 正式净值、净值日期、基金类型、基金公司和季度重仓股。
- 天天基金实验性盘中估值、估算涨跌幅、估值时间和数据来源。
- 按正式净值计算参考市值/收益，按可靠盘中估值计算估算市值/收益。
- 手动刷新、下拉刷新、页面可见期间每 30 秒自动刷新。
- 加载、空数据、失败、休市和过期状态。

本阶段没有增加 AI、新闻关联、基金推送、基金诊断或自动调仓，也没有修改 M8 行情逻辑。

## 数据口径

所有净值对象统一包含：

```text
value       数值
source      数据来源
as_of       数据对应时间
is_estimate 是否为估算
is_stale    是否可能过期
```

### 正式数据

`TushareFundProvider` 只使用 Tushare 文档化 API：

- `fund_basic`：代码、名称、类型、管理人。
- `fund_nav`：正式单位净值和净值日期。
- `fund_portfolio`：最新报告期前十大重仓股。

正式单位净值固定标记 `is_estimate=false`。季度重仓股必须显示报告期，并明确说明不代表当前实时持仓。没有 Token、积分不足或接口失败时不生成替代数据。

### 实验性盘中估值

`EastmoneyFundValuationProvider` 调用已验证可访问的公开接口：

```text
GET https://fundcomapi.tiantianfunds.com/mm/newCore/FundValuationLast
```

估值只读取接口实际返回的：

- `GSZ`：盘中估值。
- `GSZZL`：估算涨跌幅。
- `GZTIME`：估值时间。
- `SHORTNAME`：Tushare 未配置时用于精确代码搜索结果的基金名称。

接口同时返回的 `NAV/PDATE` 不作为本系统正式净值。接口没有 `GSZ/GSZZL/GZTIME` 时显示“暂无可靠数据”，不会使用重仓股自行推算。该 Provider 不使用登录、验证码、签名破解、浏览器伪装或网页解析。

这是第三方实验性数据，稳定性和持续可用性没有服务级别保证，不能称为“实时净值”。

## 交易时段与过期

交易时段按北京时间、中国工作日和法定节假日判断：上午 09:30–11:30，下午 13:00–15:00。

- 周末和法定节假日显示休市。
- 估值时间不是当天时，标记“数据可能已过期”。
- 交易时段内估值超过 `FUND_VALUATION_STALE_SECONDS` 时标记过期。
- 非交易时段保留当天最后估值，但不会显示“正在实时更新”。
- 缺失或过期估值不参与估算市值和估算收益计算。

## 持仓计算

```text
正式净值参考市值 = 持有份额 × 正式净值
正式净值参考收益 = (正式净值 - 平均成本) × 持有份额

估算市值 = 持有份额 × 可靠盘中估值
估算收益 = (盘中估值 - 平均成本) × 持有份额
估算收益率 = (盘中估值 - 平均成本) / 平均成本 × 100%
```

估算结果在接口字段和小程序文案中均明确标记“估算”。估值缺失或过期时，三个估算结果返回 `null`，页面显示“暂无可靠估值”。

## 架构与存储

```text
微信小程序 -> FastAPI Fund API -> FundService
                                  -> TushareFundProvider
                                  -> EastmoneyFundValuationProvider
                                  -> FundCacheRepository -> Redis
                                  -> FundWatchlistRepository -> PostgreSQL
                                  -> FundPositionRepository -> PostgreSQL
```

自选和持仓继续保存在 `fund_watchlists`、`fund_positions`，使用 UUID、UTC 时间、软删除和 Repository Pattern。未新增数据库表或迁移。

Redis 缓存键和默认有效期：

- `fund:valuation:{code}`：20 秒。
- `fund:nav:{code}`：1800 秒。
- `fund:profile:{code}`、`fund:catalog`：21600 秒。
- `fund:holdings:{code}`：21600 秒。

## 配置

```env
# 可选。未配置时正式净值、基金基础信息和重仓股不可用。
TUSHARE_TOKEN=
TUSHARE_BASE_URL=https://api.tushare.pro

# 实验性盘中估值开关。个人开发环境可开启。
ENABLE_EXPERIMENTAL_FUND_VALUATION=true
FUND_VALUATION_BASE_URL=https://fundcomapi.tiantianfunds.com
FUND_VALUATION_REQUEST_TIMEOUT_SECONDS=8
FUND_VALUATION_CACHE_TTL_SECONDS=20
FUND_VALUATION_STALE_SECONDS=600

FUND_CATALOG_CACHE_TTL_SECONDS=21600
FUND_NAV_CACHE_TTL_SECONDS=1800
FUND_HOLDINGS_CACHE_TTL_SECONDS=21600
FUND_REQUEST_TIMEOUT_SECONDS=15
FUND_USER_ID=00000000-0000-0000-0000-000000000001
```

Token 只能保存在后端 `.env`，不得写入小程序、日志或版本控制。Tushare 接口所需积分以其最新官方文档为准。

## API

```text
GET    /api/v1/wechat/funds/search?q=161725
GET    /api/v1/wechat/funds/watchlist
POST   /api/v1/wechat/funds/watchlist/{fund_code}
DELETE /api/v1/wechat/funds/watchlist/{fund_code}
GET    /api/v1/wechat/funds/{fund_code}
PUT    /api/v1/wechat/funds/positions/{fund_code}
DELETE /api/v1/wechat/funds/positions/{fund_code}
```

`refresh=true` 会跳过对应 Redis 缓存。小程序不会直连第三方或 PostgreSQL。

## 微信开发者工具验收

1. 后端启动后在微信开发者工具点击“编译”。
2. 点击底部“基金”，搜索 `161725`；无 Tushare Token 时仍可通过实验性 Provider 返回接口实际提供的名称。
3. 加入自选，检查“正式净值”和“盘中估值”是两个独立区域。
4. 点击基金进入详情，核对估值、估算涨跌幅、更新时间、来源、休市和过期提示。
5. 输入持有份额和平均成本并保存，核对正式净值参考结果和盘中估算结果。
6. 在估值缺失或过期的基金上确认显示“暂无可靠估值”，且没有估算市值和收益。
7. 点击“刷新”，再执行下拉刷新；保持页面可见 30 秒，确认自动刷新不改变页面结构。
8. 返回自选列表并重启 API，确认 PostgreSQL 中的自选和持仓仍存在。
9. 断开后端网络，确认页面只显示中文错误信息，不暴露异常堆栈。

## 已知限制

- 当前环境没有可用 Tushare Token 时，正式净值、基金基础信息和季度重仓股为 Pending。
- 天天基金并非所有基金都返回 `GSZ/GSZZL/GZTIME`；没有字段即没有估值。
- 实验性接口可能变更、限流或停止服务，失败时系统只做缓存和降级，不尝试绕过限制。
- 当前个人模式使用固定 `FUND_USER_ID`；公开多用户发布前需要独立的微信身份认证与权限控制。
