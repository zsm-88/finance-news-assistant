# M7 微信小程序基础框架

## 范围

M7 新增原生微信小程序和面向小程序的只读 API。它复用 M1-M6 的 Event、NewsItem、NewsAnalysis 和 MarketImpact 数据，不修改 ORM 模型、数据库迁移、采集、AI 分析、通知决策或企业微信推送。

已实现：

- 首页 Dashboard：重要新闻、最新事件、系统生成时间。
- 新闻列表：分页、重要性与分类筛选 API，重要性和发布时间排序。
- 新闻详情：正文、摘要、事件、最新 AI 分析、MarketImpact、相关新闻。
- 首页下拉刷新、新闻下拉刷新和上拉加载。
- loading、empty、error、success 四类页面状态。
- 行情、基金和 AI 基础占位页面，不包含虚假数据或后续业务。
- 开发、体验和正式环境 API 地址集中配置。
- API 参数校验、404 和通用 500 行为测试。

## 文件与职责

- `src/app/wechat/routes.py`：HTTP 路由与参数校验。
- `src/app/wechat/service.py`：只读响应组装，不直接操作 Session。
- `src/app/wechat/schemas.py`：公开响应模型和字段白名单。
- `src/app/db/repositories.py`：复用现有 Repository，增加分页、详情、事件和市场影响只读查询。
- `miniapp/services/api.js`：统一网络请求、超时和 HTTP 错误处理。
- `miniapp/config.js`：按微信运行环境选择 API 根地址。

## 安全

API 使用显式 Pydantic 响应模型。NewsAnalysis 的 `raw_response`、`prompt_text_snapshot` 和 AIUsage 不进入小程序响应；配置、密钥、Webhook 与数据库 URL 也不在响应结构内。小程序不具备数据库连接能力。

## 验收步骤

1. `docker compose ps` 确认 PostgreSQL、Redis、API 和 Worker 正常。
2. `/ready` 返回成功。
3. 新闻与 Dashboard API 返回当前 PostgreSQL 的真实数据。
4. 在微信开发者工具导入 `miniapp` 并编译。
5. 验证首页、新闻列表、详情和五个 Tab。
6. 验证首页和新闻列表下拉刷新、新闻列表上拉加载。
7. 临时停止 API，确认错误状态不展示后端异常；恢复后确认重试成功。
8. 在空数据库测试环境确认空状态。

## M7 不包含

基金估值、股票行情、完整 AI 聊天、持仓、总结、RAG、多模型协同、WebSocket 和复杂推送均未实现。M7 完成后等待人工评审，不进入后续阶段。
