# M4 AI Pipeline

M4 提供可验证、可追溯的 AI 分析框架，不包含调度和推送。

核心入口是 `app.ai.pipeline.AIPipeline.analyze(event, news, prompt_version)`。它会：

1. 构建事件和新闻上下文。
2. 从 PromptVersion 构建 System/Task Prompt 和 JSON Schema。
3. 通过 ProviderRouter 调用注册的 Provider。
4. 校验分类、1-5 星、置信度、资产和方向。
5. 校验失败写入 `ai_review_queue`，不写入分析业务表。
6. 成功时通过 Repository 同事务写入 `news_analyses`、`market_impacts`、`ai_usages`。

缓存键为 `sha256(prompt_version + content_hash)`，缓存值包含结构化输出和 Provider 元数据。
