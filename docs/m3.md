# M3 采集框架

M3 建立可扩展采集框架，不包含 AI 分析和推送实现。

## 采集链路

`SourceAdapter -> HttpFetcher -> RawNewsRepository -> DefaultNormalizer -> EventMatcher -> EventRepository/NewsRepository`

`Jin10Adapter` 是第一个 Source Adapter，端点通过构造参数注入；其他来源只需实现 `SourceAdapter` 协议。

## 断点与任务

- `SourceCursor` 按来源保存增量游标。
- `TaskQueue` 只处理统一 `Task` 对象，Task 的 `type` 用于路由，payload 保存任务参数。
- RawNews 在标准化前完整落库，便于重放和字段映射升级。

## 配置与审计

`ENABLE_CRAWLER`、`ENABLE_AI`、`ENABLE_PUSH` 默认关闭，支持独立调试。`system_configs` 用于运行时覆盖配置；后台改动应通过 `AuditLogRepository` 记录前后值和操作者。

## 迁移

M3 新增迁移 `0002_ingestion_framework`，依赖 M2 的 `0001_initial_schema`。验证：

```powershell
alembic upgrade head
alembic upgrade head
alembic downgrade 0001_initial_schema
alembic upgrade head
```
