# M12：微信小程序 UI/UX 产品化重构

## 范围

M12 只修改微信小程序前端展示和前端数据编排。后端 API、数据库、Alembic、新闻采集、行情 Provider、基金 Provider、AI、通知和企业微信链路均未修改。

## Design System

全局 Token 位于 `miniapp/app.wxss`：

- 上涨 `#c62828`，下跌 `#16845b`，中性 `#66717d`。
- 主文字 `#17202a`，页面背景 `#f5f6f7`，分割线 `#e7eaed`。
- 间距采用 8/12/16/20/24/32rpx 基础序列。
- 控件圆角 6rpx，信息卡片 10rpx。
- 使用细边框和极轻阴影，避免连续卡片堆叠。
- 页面统一安全区、骨架屏、状态页、按钮、分段控件和涨跌语义。

颜色不是唯一涨跌表达，所有涨跌值同时保留正负号和百分比。

## 共享组件

- `components/state-panel`：统一 loading、empty、error、unauthorized 和重试状态。
- `components/mini-trend`：首页上证指数近一月迷你趋势图。
- `components/finance-chart`：沿用 M11 Canvas 图表并扩大主图区域。

TabBar 使用仓库内零依赖脚本生成的 10 个透明 PNG 线性图标，没有 npm 依赖。

## 页面变化

### 首页

- 市场概览显示上证指数、深证成指、恒生指数，不显示内部 symbol。
- 第一条重要新闻作为重点内容，其余使用紧凑列表。
- 接入真实自选基金数据，删除“基金即将上线”。
- 接入上证指数历史 API，显示近一月迷你趋势图。
- 删除与新闻重复的“最新事件”区域。
- Dashboard、行情、基金、历史行情独立降级，单一 API 失败不会拖垮整页。

### 新闻

- 增加全部、宏观、市场、公司、国际前端筛选，只使用后端已有 category。
- 新闻显示相对时间，超过一天显示完整日期。
- 重点新闻使用左侧强调线，来源、分类和时间降低视觉权重。
- 详情改为连续文章流；相同的核心摘要和 AI 摘要不会重复显示。
- AI 或市场影响缺失时显示真实空状态。

### 行情

- 五个真实市场分组改为顶部切换，不再堆叠五个卡片。
- 列表隐藏内部 symbol，保留价格、涨跌额、涨跌幅和市场状态。
- 详情以 K 线/趋势图为主视觉，周期和范围控件分层展示。
- 数据来源、时间和延迟状态放到图表下方的次级区域。

### 基金

- 列表只突出正式净值、盘中估算、估算涨跌和持仓收益。
- 正式净值与盘中估算分栏展示，实验性估值没有改称实时净值。
- 详情顺序为净值、历史正式净值、持仓、季度重仓。
- Tushare 未授权时显示“历史净值数据源未授权”，不绘制假曲线。
- 过期或缺失盘中估值继续禁止驱动估算持仓收益。

### AI 助手

- 删除“M10 将支持”和“即将上线”等开发文案。
- 改为简洁的产品状态页，不提供尚未实现的输入控件。

## 人工视觉验收

1. 确保 Docker Desktop 和项目 API 正在运行。
2. 在微信开发者工具打开 `miniapp`，点击“编译”。
3. 分别使用较窄手机、标准手机和大屏手机模拟器检查以下页面。
4. 首页：检查市场、中文新闻、自选基金、趋势图和长标题换行。
5. 新闻：切换五个分类，下拉刷新，打开中文新闻详情。
6. 新闻详情：检查摘要、AI、市场影响、原文和长内容滚动。
7. 行情：切换五个市场，进入上证指数详情。
8. 行情详情：切换分时/日K/周K/月K和范围，检查 MA、成交量和延迟状态。
9. 基金：搜索、添加/移除自选、下拉刷新，打开基金详情。
10. 基金详情：检查正式净值、盘中估算、未授权历史净值、持仓编辑和季度重仓。
11. AI：确认没有过期 M10 文案。
12. TabBar：检查五个线性图标、选中态、文字和底部安全区。

## 第二阶段：FinTech 视觉与休市体验

本阶段在现有页面和数据契约上做增量升级，没有重构 M8-M11：

- 统一使用红涨、绿跌、科技蓝选中态和更清晰的数字层级。
- 首页以上证指数和真实历史趋势为主要市场快照，深证与恒生作为辅助数据。
- 行情列表改为高密度终端式信息流，行情详情扩大 Canvas 图表区域。
- 新闻首条和重点新闻提升层级，普通新闻继续使用紧凑分割线信息流。
- 基金正式净值与实验性盘中估值继续严格分离；休市时盘中区域显示“休市”。
- AI 页面仅做正式状态页视觉升级，没有伪装成可用的聊天功能。

### 最近有效数据

- 实时报价短缓存保持原策略。
- 每次获得真实有效报价时，额外写入 `market:last-valid:{symbol}`，Redis 保存 30 天。
- Provider 暂时失败时优先返回最近有效报价，并保留原价格、涨跌与时间，标记 `is_stale=true`。
- A 股在没有最近报价缓存时，使用现有 BaoStock 日 K 最后两个真实收盘点生成最近交易日快照。
- 海外标的没有可靠历史源时继续返回暂无数据，不生成或推算行情。
- 正式基金净值额外写入 `fund:last-valid-nav:{code}`，Redis 保存 30 天；绝不使用盘中估值替代正式净值。

状态区分 `trading`、`closed`、`weekend`、`holiday`、`unavailable`。小程序使用固定 `MM-DD HH:mm` 显示行情数据时间，避免把上一交易日伪装成当前日期。

## 第三阶段：终端视觉与统一休市语义

第三阶段继续在 M12 组件和页面上做增量打磨：

- 首页增加紧凑品牌标识，上证指数明确区分“现价/收盘”，辅助指数显示独立状态和数据时间。
- 自选基金首页优先显示持仓收益；休市时使用正式净值收益，不使用过期盘中估算。
- 行情市场切换改为紧凑 segmented control，列表使用小型状态标签和“最近交易日”时间。
- 行情详情在非交易时段明确显示“收盘”，并使用完整 `YYYY-MM-DD HH:mm` 时间。
- Canvas 图表支持触摸十字线和真实 OHLC、成交量、正式净值 Tooltip；没有进行插值或补造数据。
- 基金状态细分为 `closed`、`weekend`、`holiday`，正式净值只在响应展示层标记 stale，原值和原日期保持不变。
- 新闻首条作为 Lead News，AI 状态页增加低成本状态动效，不增加聊天输入或虚假能力。

行情和基金统一遵循：只有存在真实值和原始时间的数据才能标记为 stale 并继续展示；从未获得可靠数据时仍返回和显示暂无数据。

## 已知限制

- 当前 Tushare 账号积分不足，基金历史曲线只能显示未授权状态。
- BaoStock 不支持当前指数的可靠分时数据；分时页显示真实空状态。
- 海外历史行情未启用实验性 Yahoo Provider，因此无可靠历史数据时不绘图。
- 微信开发者工具 CLI 当前未开放服务端口，自动打开/编译命令会超时，最终像素布局需人工验收。
