# M11 第一阶段：历史行情与基金净值曲线

## 范围

本阶段在不修改 M8 实时报价、M9 盘中估值/持仓和 M10 新闻链路的前提下，增加：

- A 股及指数历史行情契约、Provider、Redis 缓存和微信 API。
- Tushare 正式历史净值契约、Provider、Redis 缓存和微信 API。
- 原生微信小程序 Canvas 2D K 线、MA、成交量和净值曲线组件。

本阶段没有新增数据库表或 Alembic migration。

## 数据源边界

### 历史行情

- A 股及指数使用 BaoStock 官方客户端，当前项目内的 4 个 A 股指数支持日 K、周 K、月 K。
- BaoStock 历史行情属于收盘后数据，API 固定返回 `is_delayed=true`。
- BaoStock 不提供当前项目指数的可靠分时历史，因此分时返回 `unavailable`，不生成曲线。
- 港股、美股、大宗商品和外汇没有启用实验性 Yahoo 历史 Provider，返回 `unavailable`，不伪造数据。
- MA5、MA10、MA20、MA60 只根据 Provider 返回的收盘价在本地确定性计算。

### 基金历史净值

- 只调用 Tushare 官方 `fund_nav`，字段为 `nav_date`、`unit_nav`、`adj_nav`。
- 历史响应固定为 `is_estimate=false`，不会读取或混入天天基金 `GSZ`、`GSZZL`。
- 当前 Token 积分不足时返回 `status=unauthorized` 和“历史净值数据源未授权”，不绘制空白假图。

## API

### 历史行情

```text
GET /api/v1/wechat/market/{symbol}/history
```

参数：

- `period=intraday|day|week|month`
- `range=1d|1m|3m|6m|1y|5y`

响应包含：

- `items[].timestamp/open/high/low/close/volume`
- `items[].ma5/ma10/ma20/ma60`
- `source/as_of/is_delayed/timezone/status/message`

Redis Key：`market:history:{symbol}:{period}:{range}`，默认 TTL 900 秒。

### 基金历史净值

```text
GET /api/v1/wechat/funds/{fund_code}/nav-history
```

参数：

- `range=1m|3m|6m|1y`
- `refresh=true|false`

响应包含：

- `items[].nav_date/unit_nav/adj_nav`
- `source/as_of/is_estimate/is_stale/status/message`

Redis Key：`fund:nav-history:{fund_code}:{range}`，默认 TTL 1800 秒。

## 配置

```text
MARKET_HISTORY_CACHE_TTL_SECONDS=900
FUND_NAV_HISTORY_CACHE_TTL_SECONDS=1800
TUSHARE_TOKEN=
```

`TUSHARE_TOKEN` 仍为可选配置。未配置或无 `fund_nav` 权限不会阻止 API、行情、新闻、Worker 启动。

## 小程序验收

1. 在微信开发者工具重新编译 `miniapp`。
2. 打开“行情”，进入“上证指数”。
3. 切换日 K、周 K、月 K及时间范围，检查 K 线、MA、成交量、来源、截至时间和延迟标记。
4. 切换“分时”，确认无可靠数据时显示中文空状态且没有假图。
5. 进入美股或港股详情，确认显示“当前标的暂无可靠的历史行情数据”。
6. 打开基金详情，切换 1 月、3 月、6 月、1 年。
7. 当前 Tushare 权限不足时，应显示“历史净值数据源未授权”。
8. 下拉刷新行情和基金详情，确认原有报价、正式净值、实验性估值及持仓展示不受影响。

## 已知限制

- BaoStock 不能覆盖当前项目中的港股、美股、商品和外汇标的，也不能提供这些指数的分时数据。
- 当前 Tushare 账号积分不足，基金历史正式净值真实曲线处于 Pending。
- 图表使用原生 Canvas 2D，已通过逻辑测试；最终像素布局和触控体验需要在微信开发者工具人工验收。
