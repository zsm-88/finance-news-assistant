# AI财经助手小程序

本目录是原生微信小程序前端。首页和新闻页面读取 PostgreSQL 中的真实财经新闻；行情中心通过后端 Provider 和 Redis 短缓存读取真实市场数据；基金中心通过 Tushare 的文档化接口读取正式净值和季度持仓，自选与个人持仓保存在 PostgreSQL。AI助手仍是后续阶段入口。

## 本地运行

1. 安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 在开发者工具中选择“导入项目”，目录选择本仓库的 `miniapp`。
3. 本地预览可使用测试 AppID；发布和真机调试必须改为自己的小程序 AppID。
4. 在仓库根目录执行 `docker compose up -d`，确认 `http://localhost:8000/ready` 返回 `{"status":"ready"}`。
5. 默认开发地址位于 `config.js`，值为 `http://localhost:8000`。开发者工具本地调试时需要关闭“校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。
6. 编译项目，打开首页后应看到当前 PostgreSQL 中的真实财经新闻和行情摘要。

## API 配置

`config.js` 按微信环境维护一个 API 地址：

- `develop`：本机开发者工具，默认 `http://localhost:8000`
- `trial`：体验版，必须替换为真实公网 HTTPS 地址
- `release`：正式版，必须替换为真实公网 HTTPS 地址

不要在页面中单独写 API 地址，也不要把任何 AI Key、企业微信 Webhook 或数据库凭据放入小程序代码。

## 真机和发布要求

手机中的 `localhost` 指手机本身，不能访问电脑上的 API。真机调试、体验版和正式版必须满足：

1. 后端部署到可从公网访问的 HTTPS 域名。
2. HTTPS 证书有效，TLS 配置符合微信要求。
3. 在微信公众平台的“开发管理 -> 开发设置 -> 服务器域名”中，把该域名添加到 `request` 合法域名。
4. 将 `config.js` 的 `trial` 和 `release` 地址替换为同一 HTTPS API 根地址。
5. 不要把裸 IP、HTTP 地址或带路径的 URL 配置为正式环境合法域名。

## 手工验证

- 首页显示加载状态后展示真实新闻和最新事件。
- 首页展示上证指数、沪深300、纳斯达克指数和黄金行情摘要。
- 首页下拉刷新可以更新数据。
- 新闻 Tab 显示列表，上拉到底可继续加载。
- 点击新闻可以打开详情，显示 AI 分析和结构化市场影响（数据库存在时）。
- 断开后端后页面显示“加载失败，请稍后重试”，恢复后可点击重试。
- 空数据库环境显示空状态。
- 行情 Tab 按市场展示 12 个标的，支持手动、下拉和定时刷新。
- 点击行情可打开详情；数据源失败时显示“暂无数据”，不得出现测试价格。
- 基金 Tab 支持代码/名称搜索、自选基金和持仓录入；缺少 `TUSHARE_TOKEN` 时显示明确的未配置状态。
- 基金详情只显示正式净值，并固定说明“盘中估算：暂无可靠数据”；季度重仓股必须带报告期。
- 保存持仓后，市值和收益按最新正式净值计算，重启 API 后自选和持仓仍然存在。
- 首页、新闻、行情、基金、AI助手五个 Tab 可以正常切换。

小程序不需要 Docker，也不直接访问 PostgreSQL。

页面状态与导航配置的自动测试可执行：

```powershell
node --test miniapp/tests/pages.test.js
```
